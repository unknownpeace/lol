Все сервисы работают с «зелёным замком» на смартфонах и ПК. Установка локальных CA не требуется.

          

        

        
      


      

        

          

            

              🏛️ Центр доверия сертификатов
            

            

              Установите сертификат для бесшовного доверия доменам https://*.lan на смартфонах и ПК при оффлайн-работе.
            

          

          

            
              📥 Для Windows / Linux (.crt)
            
            
              📱 Для Android (.cer)
            
          

        

        

          Invoke-WebRequest -Uri "http://ca.lan/homelab-root-ca.crt" -OutFile "$env:TEMP\homelab-ca.crt"; Import-Certificate -FilePath "$env:TEMP\homelab-ca.crt" -CertStoreLocation Cert:\LocalMachine\Root
